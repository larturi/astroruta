# AstroRuta - 28 días para entender astrología

Sitio web interactivo, en español y sin dependencias externas.

## Cómo usar

Abrí `index.html` en Chrome, Firefox, Safari o Edge, también en el celular. Podés abrirlo sin conexión y sin servidor.

## Funcionalidades

- 28 lecciones detalladas en 5 capítulos, con ejemplos y mini misiones.
- Un cuestionario interactivo y una tarjeta de memoria por lección.
- Repaso aleatorio de 28 tarjetas, glosario consultable y buscador de lecciones.
- XP, insignias, racha diaria, seguimiento de progreso, guardados y notas personales.
- Tema oscuro y claro.
- Descarga del plan de 28 días en formato `.ics` para importar en tu calendario.
- Progreso guardado exclusivamente en `localStorage` del navegador, sin cuenta ni servidor.

## Archivos

- `index.html`: versión completa y autónoma, recomendada para abrir directamente.
- `content.js`: datos de las 28 lecciones.
- `style.css`: estilos.
- `app.js`: lógica de interacción.

## Publicación

Si deseás publicarlo en un hosting estático (Vercel, Netlify o GitHub Pages), alcanza con subir `index.html` como página principal. Los otros archivos del proyecto se incluyen para facilitar modificaciones, pero `index.html` ya tiene todo incorporado.

## Importante

La astrología se presenta como una tradición simbólica y cultural. No hay evidencia científica sólida de que las posiciones planetarias determinen la personalidad o predigan eventos personales.
